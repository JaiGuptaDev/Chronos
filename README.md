# Chronos
Chronos is a modern, dark-mode study session tracker and analytics dashboard built with HTML, Tailwind CSS, and Chart.js. It features live time tracking, detailed history logs, heatmaps, and subject breakdown analytics—all saved locally using IndexedDB.
